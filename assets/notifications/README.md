# Garden reminder illustration

`garden-reminder.png` was generated with the built-in ImageGen tool in generate mode, then copied unchanged into this directory. The Android app makes a smaller cached PNG at runtime for rich notifications. No external image service is contacted by the app.

Prompt used:

> Use case: stylized-concept. Asset type: wide image for rich Android notifications in the Money Plant personal finance app. Create a charming premium 3D clay illustration, landscape aspect ratio roughly 2:1. A cute small green money plant with two round glossy leaves and a smiling warm ivory ceramic pot, next to a tiny lilac watering can and a little peach coin purse. Two small pink hearts and a few soft sparkles float around them. Calm warm ivory background, fresh lime, forest green, pastel lilac and peach, soft studio lighting, rounded tactile shapes, gentle shadows. All subjects centered with generous padding for Android notification cropping, friendly Gen Z aesthetic consistent with a clean cream and forest finance UI, playful but refined. No text, numbers, brand logos, watermarks, or UI frames.

The launcher icon and opening scene are separate native vector/Flutter drawings, so they remain sharp at different device sizes.
